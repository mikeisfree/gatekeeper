Wpisz PIN

PIN to tylko bariera kosmetyczna — kod tej strony jest publiczny. Realnym zabezpieczeniem jest token GitHub, który nigdy nie opuszcza Twojej przeglądarki.

GitHub Token

Wygeneruj token z prawem zapisu do repozytorium gatekeeper:
fine-grained → Contents: Read and write,
albo classic → scope repo (lub public_repo).
Token jest przechowywany tylko w pamięci tej przeglądarki (sessionStorage).
